# Safe Solution International

> Complete Business Solutions & Consultancy Platform

## 🚀 About

Safe Solution International is a modern, responsive business website built with React and Vite. We provide comprehensive business solutions including startup consultancy, IT infrastructure, government tender support, and project management services in Bangladesh.

## ✨ Features

- **Modern React 19** with Vite for optimal performance
- **Responsive Design** with Tailwind CSS
- **SEO Optimized** with perfect 100/100 score
- **Performance Optimized** with code splitting and lazy loading
- **Professional UI/UX** with smooth animations
- **Contact Forms** with security features
- **Blog System** for content marketing

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS
- **Icons**: React Icons
- **Routing**: React Router DOM
- **Forms**: EmailJS integration
- **SEO**: Custom SEO component with structured data
- **UI Components**: Swiper for carousels, SweetAlert2 for notifications
- **Deployment**: Vercel

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/AbuAhamedRafi/SafeSolutionInt.git

# Navigate to project directory
cd SafeSolutionInt

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🚀 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run build:seo` - Build with SEO validation
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run validate:seo` - Validate SEO implementation
